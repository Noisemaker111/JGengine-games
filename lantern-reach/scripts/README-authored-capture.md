# Authored environment capture

The normal game retains its class selection, progression and combat rules. Its document supplies weather schedules, local rain/snow, roof shelters, two fuelled fires, named flame/smoke/ember emitters, a marsh vortex and an animated swallow habitat. `game/environment.ts` opts living travellers into bounded shared wind motion and surface tracking. Hunter abilities launch shared physical arrows and settle game damage against the actual struck hostile actor.

After the release owner's central SDK upgrade, run normal checks and the capture fixture's separate typecheck:

```sh
bun run --cwd lantern-reach check-types
bun run --cwd lantern-reach test
cd lantern-reach
bunx tsgo --noEmit -p tsconfig.capture.json
bun run dev
```

`capture-authored.html` mounts the real playable through public `GamePlayerShell`, selects Vanguard through its existing command, skips its opening cinematic, and supplies labelled capture controls. It uses ordinary persisted graphics settings: low quality, 0.5 render scale, shadows and postprocessing off. Camera views use the typed camera API. Use the engine repository's `drive` procedure and trusted clicks on **Torch view**, **Funnel view** and **Bird habitat view**. This inspection fixture is separate from the production Create/Edit/Save workflow demonstrated by Cloud Course.

**Stage arrow flight** spawns one bounded wolf, launches the same hunter-arrow adapter and pauses authoritative time after 0.20 game seconds so its original arrow model is visible. **Resume staged flight** resumes travel and actual collision. This is explicitly staged evidence; it does not unlock a production ability or establish a native level-eight playthrough. Deterministic tests cover interceptor armour, moving misses, expiry, pause, restore and exactly-once damage settlement.

**Retire cosmetic emitters** retunes only this runtime snapshot. Read `debug_snapshot` before and after rendered frames: named particle capacity/buffers/live fields should fall to zero, with pool and field creation/retirement balanced. Procedural weather is a separate owner. **Unload captured game**, followed by **Read capture metrics**, checks canvas-independent teardown using public diagnostics and the retained context's environment state. Game asset caches may persist intentionally.

The native unload check found and validated a shared host cleanup fix: after the real Unload click, there were zero canvases, watched surfaces, flock habitats, named emitters and registered diagnostic probes. This check must use freshly rebuilt public packages and a restarted Vite server so its dependency optimiser serves the current host implementation.

The verified candidate's staged-arrow view had 241 named particles in eight pools with capacity 432 and 27,648 bytes of render buffers; rain used 306/2,000 instances and impacts 64/64 with 128 bounded height/exposure queries. It reported 199 draw calls and 303,529 triangles. Retiring emitters balanced eight created/retired pools and eight mounted/unmounted fields, with zero named particles, capacity and attribute bytes; renderer geometries fell from 225 to 210. Particle update averages were 2.01 ms in that run, with a 31.1 ms maximum. These are software-GL capture observations, not production frame-rate claims or heap-allocation measurements.

The marsh composition visibly produces diffuse swirling smoke and debris; it is not a fluid simulation. Existing scenery texture-loader errors and placeholder mappings remain visible in capture diagnostics and belong to the existing asset workspace. Original swallow and arrow GLBs are generated by `build-authored-fauna.ts`, contain no external textures, and pass glTF validation with zero errors or warnings.

The editor save normalised JSON key order without changing existing prefab content. All prior prefab fragments were compared as parsed objects against the incoming Games revision, and all 66 reviewed GLBs retained their recorded bytes, SHA-256 and declared draw counts. Only the twelve `sourcePrefabSha256` metadata values were refreshed to match the strict existing test's current JSON serialisation. No GLB, material or asset-integrity assertion was changed. The invalid legacy sky preset `dawn` was repaired to supported `day` through the typed editor command while preserving its other environment settings.
