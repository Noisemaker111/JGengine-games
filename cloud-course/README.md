# Cloud Course

An original toy-sport jump course with a player creator. The main menu's **Create or edit a course** opens the real JGengine editor. Name a creation, place approved pads in the Content Browser, save, playtest, return to editing, and reopen it from the saved scenes list. Named saves use the injected `CreatorDocumentStorage` adapter backed by browser `localStorage`; reloading preserves them. Export/import use the same document and budget validation as edits and saves.

The game owns its mascot, course objects, route rules, timer, checkpoints, missed-jump retry, and menu. JGengine owns editing, undo/redo, storage revisions, snapshot isolation, collision, movement, models, animation, and host mode transitions. Playtests clone the document; runtime motion cannot write into the authored scene.

The catalog contains five original objects: wide pad, narrow step, yellow checkpoint, violet finish, and coral bumper. Budgets allow twelve named creations, 48 placed objects and 96 KB per document. Courses keep exactly one start and at least one finish. Models are generated by `scripts/author-models.py`; no external art is required. Positions follow shared authored-object XZ placement and `meta.verticalOffset` height conventions.

From the Games workspace, after the release owner's central SDK catalog upgrade:

```sh
bun install
bun run --cwd cloud-course dev
bun run --cwd cloud-course check-types
bun run --cwd cloud-course test
bun run --cwd cloud-course build
```

The portable `scripts/drive.mjs` and `scripts/shoot.mjs` use the repository's trusted-event capture procedure. Use the full desktop viewport for the editor's docked Content Browser.
