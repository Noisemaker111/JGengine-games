# Cloud Course

Original toy-sport obstacle course on soft inflatable pads above a lilac landing field.
Players shape short jump routes, save a named course, test it and revise the same work.
The core choice is a safe wide pad versus a shorter narrow jump. A missed jump pauses
at a visible tumble screen, and the last checkpoint offers a quick retry.

Turquoise pads, coral bumpers, warm yellow checkpoints and violet finish mats carry
route semantics. The runner is an original cream-and-coral round mascot with two dark
eyes and short animated feet. Assets are generated locally from original geometry.

The menu resembles a bold toy-sport event board: oversized slanted title, numbered
route cards, thick dark outlines and offset shadows. System sans-serif gives plain
instructions; tabular monospace carries times. Buttons stay large on touch screens.
No dashboard tiles, stock glass panels or copied game branding.

Starter route: safe start → two short jumps → checkpoint → narrow combination → finish.
Base walking speed is 5 m/s (before the engine movement multipliers), gravity is 24 m/s² and jump velocity is 9 m/s. The first jump
has a 1 m gap; the final narrow gap is 1.5 m. One banked checkpoint separates learning
from mastery. Completion is reaching the finish after that checkpoint. A fresh player
must be able to save, reopen, finish a playtest and return to unchanged authored work.
